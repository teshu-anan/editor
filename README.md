# SimpleEditor —— 简单文本编辑器

《Qt 应用程序开发》实验二：多窗口文本编辑器（Qt 5.12 + MinGW，qmake 工程）。

## 直接运行

不想编译的话，双击上级目录 `SimpleEditor-可直接运行\SimpleEditor.exe` 即可（已打包 Qt 运行库）。

## 在 Qt Creator 中打开

1. 文件 → 打开文件或项目 → 选择 `SimpleEditor.pro`
2. 配置项目时勾选 Debug
3. 点击左下角绿色三角运行

## 功能一览

| 分类 | 功能 |
| --- | --- |
| 文件 | 新建（多窗口）、打开、保存、另存为、每 30 秒自动保存（选做） |
| 编辑 | 撤销 / 重做 / 剪切 / 复制 / 粘贴 / 删除 / 全选，按钮使能状态自动联动 |
| 查找 | 查找（区分大小写、全字匹配、向上查找、环回连续查找）、替换、全部替换（可一次撤销） |
| 格式 | 字体大小、字体颜色、编辑器背景色、自动换行 |
| 视图 | 工具栏 / 状态栏显隐，状态栏显示行列、字符数、保存状态 |
| 其他 | 行号显示与当前行高亮（QPlainTextEdit 派生 + 提升）、标题随修改状态变化、关于对话框 |

## 目录结构

```
SimpleEditor/
├── SimpleEditor.pro        工程文件
├── main.cpp                入口
├── mainwindow.h/.cpp/.ui   主窗口（文件/编辑/格式/视图逻辑）
├── codeeditor.h/.cpp       派生编辑控件：行号 + 当前行高亮

├── replacedialog.*         替换对话框
├── aboutdialog.*           关于对话框
├── resources.qrc           资源
└── icons/*.svg             16 个工具栏图标
```

## 命令行编译（可选）

```bat
cd SimpleEditor
qmake SimpleEditor.pro
mingw32-make release
```

## 自动保存与边界处理

- 自动保存：`QTimer` 每 30 秒触发一次，仅在「已关联文件路径 + 文档被修改」时写盘，
  状态栏同时提示保存结果；未保存过的新文档不会被偷偷写进磁盘。
- 关闭保护：文档有未保存修改时弹窗询问「保存 / 不保存 / 取消」，取消则中止关闭。
- 文件读写统一走 `QSaveFile`，写入失败不会破坏原文件。
- 编码识别：带 UTF-16 BOM 的文件按 UTF-16 读，其余按 UTF-8 读；
  内容中含 `\0` 的二进制文件直接拒绝并提示，避免把乱码灌进编辑器。
- 更多异常场景的实测记录见 `测试记录.md`。
